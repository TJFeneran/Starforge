# Beam VFX

Source: [Beam VFX](https://binbun3d.itch.io/beam-vfx), free base effect, downloaded September 22, 2026.

License: CC0 1.0 Universal, as stated on the source page. Attribution is not required.

The original archive resource paths were changed to keep this free edition self-contained in `assets/BinbunVFX/BeamVFXFree/`. Bundled `.uid` and `.import` sidecars were omitted so Godot generates paths and UIDs for this location.

`vfx_beam_controller.gd` also has a `show_caps` option so the game's warning and player beams can hide the pack's solid start and end spheres.
