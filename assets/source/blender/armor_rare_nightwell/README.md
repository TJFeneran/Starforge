# armor_rare_nightwell Meshy rig

The full Meshy 7 source model is preserved, including its original triangle count, UV layout and texture materials. Only fitting to the shared Exo Gray bind pose and vertex skin weights are added. Uses the exact original 112-bone skeleton.

Reproduce from project root with `blender -b -t 2 --python assets/source/blender/armor_rare_nightwell/rig_meshy.py`. The script exports the final preview GLB, editable .blend, validation JSON and renders bind/walk/run/aim poses.

Character generation: `assets/source/meshy/armor_rare_nightwell/armor_rare_nightwell.glb`.
