# Ridge

Authored from `meshy_views_v2/gun_rifle_common_ridge` side/top/front only. Editable beveled source meshes, packed PBR maps, named assembly groups, Fire bolt/trigger and Reload magazine animations. Non-emissive ballistic rifle with open carry handle and cobalt magazine shell. Godot forward -Z, origin at grip.

Rebuild: `blender -b --factory-startup -t 4 --python tools/build_ridge.py`.

Animations are presentation-ready assembly motions; gameplay hookup is separate.
