# Longpath

Authored from `meshy_views_v2/gun_rifle_uncommon_longpath` side/top/front only. Editable beveled source meshes, packed PBR maps, named assembly groups, Fire bolt/trigger and Reload magazine animations. Cyan emissive scope glass; folded bipod assembly. Godot forward -Z, origin at grip.

Rebuild: `blender -b --factory-startup -t 4 --python tools/build_longpath.py`.

Animations are presentation-ready assembly motions; gameplay hookup is separate.
