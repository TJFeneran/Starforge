# armor_rare_riftward — Meshy 7 rig

Rebuild with `blender -b -noaudio --python assets/source/blender/armor_rare_riftward/rig_meshy.py`.

The source Meshy geometry, UVs and materials are preserved. Mesh positions are fitted to the project Exo Gray bind skeleton and skin weights are transferred and corrected around rigid helmet, limbs and feet. The 112 reference bones and their order are preserved. Output is `assets/models/gear/armor/previews/armor_rare_riftward.glb`.

Proof renders cover bind, walk, run and pistol aim using the existing project animation poses. The source Meshy visor is dark and lacks the concept amber glow; the original material is preserved.
