# Contributing

- Never commit or push directly to `main`.
- Start every piece of work on a new branch: `git switch -c <your-name>/<short-topic>` from an up-to-date `main`.
- Push the branch and open a pull request into `main`; merge only after review.
- Run `godot --headless --import --path .` before opening a PR to confirm the project imports cleanly.
- See `AGENTS.md` for environment setup and validation steps.
